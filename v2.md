# Radhna Cuisine — Restaurant Management System

## Project Overview

A **monorepo** restaurant management system with four frontend apps and one backend API, connected to a PostgreSQL database.

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| **Backend** | NestJS 11 + Prisma 7 + PostgreSQL 15 |
| **Customer Web** | Next.js 19 (App Router), React 19, Tailwind 4, Zustand |
| **Admin Web** | Vite 8 + React 19 + Tailwind 4 + Recharts |
| **Chief Web** | Vite 8 + React 19 + Tailwind 4 + Socket.io Client |
| **Real-time** | Socket.io (WebSocket) for kitchen display |
| **Auth** | JWT (Passport), bcrypt password hashing |
| **Payments** | Razorpay integration |
| **Notifications** | Nodemailer (SMTP email) + Twilio (SMS) |
| **Monorepo** | npm workspaces |

## Backend API (`services/backend-api`)

### Auth Module
| Endpoint | Auth | Description |
|----------|------|-------------|
| `POST /api/auth/login` | Public | Login with email + password |
| `POST /api/auth/register` | Public | Register new customer account |
| Uses JWT tokens, Passport strategy, bcrypt hashing | | |

### Menu Module
| Endpoint | Auth | Description |
|----------|------|-------------|
| `GET /api/menu/categories` | Public | Active categories (ordered by display order) |
| `GET /api/menu/items` | Public | Enabled food items (optional `?categoryId=` filter) |
| `GET /api/menu/specials` | Public | Today's specials |
| `GET /api/menu/categories/all` | JWT | All categories (admin) |
| `POST /api/menu/categories` | JWT | Create category |
| `PATCH /api/menu/categories/:id` | JWT | Update category |
| `DELETE /api/menu/categories/:id` | JWT | Delete category (fails if has items) |
| `GET /api/menu/items/all` | JWT | All items (admin, optional `?categoryId=`) |
| `POST /api/menu/items` | JWT | Create food item (optional `stock`) |
| `PATCH /api/menu/items/:id` | JWT | Update food item + stock |
| `DELETE /api/menu/items/:id` | JWT | Delete item |

Ratings: Food items include `averageRating` and `totalReviews` from the Reviews aggregation.

### Orders Module
| Endpoint | Auth | Description |
|----------|------|-------------|
| `POST /api/orders` | Public | Place order (table number, items, optional couponCode) |
| `GET /api/orders/track/:id` | Public | Track order by ID |
| `GET /api/orders/my-orders` | JWT | Customer's order history |
| `GET /api/orders/analytics?days=30` | JWT | Revenue, popular items, peak hours, payment breakdown, discount stats |
| `GET /api/orders/overview` | JWT | Today's revenue, order count, active tables |
| `GET /api/orders` | JWT | List all orders (optional `?status=`, `?table=`) |
| `GET /api/orders/:id` | JWT | Full order details |
| `PATCH /api/orders/:id/status` | JWT | Update order status (state machine validated) |
| `PATCH /api/orders/:id/cancel` | JWT | Cancel order |

**Order state machine:** `PLACED → ACCEPTED → PREPARING → READY → COMPLETED` (CANCELLED from PLACED/ACCEPTED/PREPARING).

**Notifications:** On create and status changes → email (if email available) + SMS (if phone available). Fire-and-forget.

**Stock deduction:** Items with `ProductionStock` have quantity decremented on order placement.

### Reviews Module
| Endpoint | Auth | Description |
|----------|------|-------------|
| `POST /api/reviews` | JWT | Submit review (rating 1-5, optional comment). One per item per customer. |
| `GET /api/reviews/item/:foodItemId` | Public | Get reviews + average rating |

### Coupons Module
| Endpoint | Auth | Description |
|----------|------|-------------|
| `POST /api/coupons/validate` | Public | Validate coupon code (date, usage limit checks) |
| `GET /api/coupons` | JWT | List all coupons (admin) |
| `POST /api/coupons` | JWT | Create coupon (PERCENTAGE/FLAT, dates, limit) |
| `DELETE /api/coupons/:id` | JWT | Delete coupon |

### Users Module
| Service | Description |
|---------|-------------|
| `findByEmail()` | Lookup by email for auth |
| `findById()` | Lookup by ID |
| `createUser()` | Create with bcrypt-hashed password |

### Billing Module
| Endpoint | Auth | Description |
|----------|------|-------------|
| `POST /api/billing/:id/create-order` | Public | Create Razorpay payment order |
| `POST /api/billing/verify` | Public | Verify Razorpay payment signature |
| `POST /api/billing/webhook` | Public | Razorpay webhook handler |

### Inventory Module

| Endpoint | Auth | Description |

| `GET /api/inventory` | JWT | List inventory items |
| `POST /api/inventory` | JWT | Create inventory item |
| `PATCH /api/inventory/:id` | JWT | Update item |
| `DELETE /api/inventory/:id` | JWT | Delete item |

### Tables Module
| Endpoint | Auth | Description |
|----------|------|-------------|
| `GET /api/tables` | JWT | List all tables |
| `POST /api/tables` | JWT | Create table |
| `DELETE /api/tables/:id` | JWT | Delete table |

### Health Module
| Endpoint | Description |
|----------|-------------|
| `GET /api/health` | Returns status, uptime, DB health check |

### Infrastructure
- **Rate limiting:** 10 req/s short, 50 req/10s medium, 200 req/min long
- **Logging:** Winston (colorized console, error.log, combined.log)
- **Swagger:** Available at `/api/docs`
- **CI/CD:** GitHub Actions (4 jobs: backend, customer-web, admin-web, chief-web)

## Customer Web (`apps/customer-web`) — Next.js

### Pages
| Route | Type | Description |
|-------|------|-------------|
| `/` | Server | Home page |
| `/menu` | Server | Menu browser with categories, dietary filters, ratings, today's specials banner |
| `/menu?filter=veg\|nonveg` | Server | Dietary filtered views |
| `/order/[id]` | Client | Real-time order tracking (polls every 5s), status timeline, review form on completion |
| `/orders` | Client | Order history (auth required) |
| `/auth/login` | Client | Login/Register with tabs |

### Features
- **Cart:** Zustand + persist, items, quantities, special instructions, auto-open on add
- **Coupons:** Input field, validate against backend, live discount display
- **Reviews:** Star rating on FoodItemCard, submit review on completed orders
- **Auth:** JWT auth with persist, login/register, user menu dropdown
- **Payments:** Razorpay checkout integration
- **Responsive:** Mobile-first, drawer cart, sticky navbar

## Database Schema

### Core Models
- **User** — auth, roles (SUPER_ADMIN, CHIEF, CUSTOMER), status
- **Category** — menu categories with display order
- **FoodItem** — menu items (veg/non-veg, popular, special, stock)
- **ProductionStock** — per-item inventory tracking

### Operations Models
- **Table** — restaurant tables with QR codes
- **Order** — full order lifecycle (status, subtotal/tax/discount/total, payment)
- **OrderItem** — line items linking orders to menu items
- **Payment** — payment transactions with Razorpay gateway tracking

### Engagement Models
- **Review** — customer ratings (1-5) with unique constraint per customer+item
- **Favorite** — customer favorites with unique constraint
- **Coupon** — discount codes (PERCENTAGE/FLAT, date range, usage limits)
- **Notification** — in-app notifications by type
- **AuditLog** — admin action audit trail
- **InventoryRawMaterial** — ingredient-level inventory

## Running the Project

```bash
# Start PostgreSQL
docker-compose up -d postgres

# Prisma migration
cd database && npx prisma migrate deploy && npx prisma generate

# Start backend
cd services/backend-api && npm run start:dev

# Start customer web
cd apps/customer-web && npm run dev

# Start admin web
cd apps/admin-web && npm run dev

# Start chief web
cd apps/chief-web && npm run dev
```
